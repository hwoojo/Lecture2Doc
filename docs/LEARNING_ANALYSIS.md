# 강의 중요도와 AI 기반 개념 등장 시간

## 목표

강의 영상을 전부 다시 보지 않아도 핵심 판서와 주제 개념을 먼저 확인하고, 필요한 음성·필기 시점으로 바로 이동하도록 돕는다. 원본 판서, 전사문, 영상 시간 근거는 유지하고 학습 우선순위를 보조한다.

## 화면 구성

학습 분석 영역은 판서·영상·전사 작업 영역의 **맨 아래**에 배치한다.

- **중요 판서 구간**: 페이지별 중요도, 판단 근거, 원본 영상 시간. 각 판서 카드 아래에는 해당 구간만 재생하는 소형 영상 플레이어를 표시한다.
- **개념별 등장 시간**: 강의 주제와 직접 관련된 핵심 개념 최대 5개, 각 개념의 필기·음성 등장 시간
- 별도의 "현재 판서와 연결된 음성 설명" 목록은 일반 음성 전사 영역과 중복되어 화면에서 제거했다.

시간 버튼을 누르면 해당 판서 또는 음성 구간으로 이동한다. 중요 판서 카드의 미니 플레이어는 판서 시작 시점에서 재생하고 판서 종료 시점에서 자동으로 멈춘다. 다른 미니 플레이어를 재생하면 이전 미니 플레이어와 상단 원본 플레이어는 일시 정지한다. 미리보기는 대표 원본 프레임을 포스터로 사용하며 영상 데이터는 재생할 때 로드한다.

## 중요도 계산

페이지 중요도 0~100점은 설명 가능한 규칙 기반 신호로 계산한다.

| 신호 | 가중치 |
|---|---:|
| 교수자의 시험·중요·암기·주의·정의·유도·예제 강조 표현 | 40% |
| 판서 개념이 음성에서 반복되는 정도 | 30% |
| OCR 판서 개념과 음성 전사의 일치 | 22% |
| 신뢰 가능한 판서 OCR 근거 | 8% |

사용할 수 있는 자료가 일부뿐이면 가중치를 다시 정규화한다. 음성 전사가 없으면 음성 기반 페이지 중요도는 미산정으로 둔다. 중요도 점수는 시험 출제 확률이나 학습 성과를 보장하는 값이 아니다.

## AI 기반 핵심 개념 선별

개념 후보는 신뢰 가능한 판서 OCR과 음성 전사에서 추출한다. 한국어 조사와 흔한 말버릇·일반 표현을 먼저 걸러낸다. 예를 들어 "한번", "것도", "이거", "이제", "내용", "부분", "설명" 등은 학습 개념 후보에서 제외한다.

로컬 Qwen 비전·언어 모델이 전사문 일부, 읽을 수 있는 판서 OCR 일부, 후보 용어와 각 후보의 근거를 읽고 강의의 실제 주제를 파악해 핵심 개념을 최대 5개 선별한다. 같은 개념의 띄어쓰기·표현 차이는 하나로 묶는다. AI가 고른 항목도 반드시 기존 OCR·전사 후보와 연결되어야 하므로 원문에 없는 개념을 새로 만들어 표시하지 않는다.

기본 모델은 Mac 통합 메모리에 따라 자동 선택한다. Apple Silicon 32GB 이상은 `qwen3.8:27b-mlx`, 24GB 이상은 `qwen3-vl:8b`, 16GB 이상 24GB 미만은 `qwen3-vl:4b`, 16GB 미만은 `qwen3-vl:2b`를 사용한다. 전체 기본 모델 세트는 `lecture2doc setup-models`로 준비하며 Qwen만 받을 때는 `lecture2doc qwen-models`를 사용한다. Qwen3.8은 Ollama 0.40.0 이상, 작은 Qwen3-VL은 0.12.7 이상이 필요하다. Ollama가 실행되지 않거나 모델이 없으면 외부 AI를 호출하지 않고 기본 필터로 최대 5개를 표시한다. 분석 전체가 중단되지는 않는다.

**개인정보·비용:** 개념 선별 요청은 로컬 Ollama 주소(`127.0.0.1:11434`)로만 전송한다. 외부 AI API 키나 토큰 사용료는 필요하지 않다. 전사문과 OCR 텍스트는 Mac을 벗어나지 않는다. 최초 Qwen 모델 다운로드에만 인터넷이 필요하다.
## 시간 정보 해석

- **필기 시간**: 기존 판서 페이지의 `start`~`end` 범위다. 해당 판서 상태가 영상에서 관측되는 구간이며 개별 글자가 쓰인 정확한 순간은 아니다.
- **음성 시간**: 자막 또는 Whisper 전사 세그먼트의 `start`~`end` 범위다. 개념어가 실제 텍스트에서 확인된 발언 구간을 표시한다.
- 같은 개념이 여러 번 언급되면 각 발언 시각을 별도로 보존한다.

모든 시간은 영상 시작을 0초로 하는 초 단위다. Whisper나 자막의 시간 경계 정밀도를 넘어서 단어 단위의 정확한 발화 시점을 보장하지 않는다.

## 데이터 위치

결과는 `manifest.json`의 `learning_analysis`에 저장한다.

- `status`: `complete`, `partial`, `insufficient_evidence`
- `pages[]`: 페이지별 중요도, 판단 신호, AI가 선별한 페이지 개념
- `concepts[]`: AI가 선별한 최대 5개 개념, 관련 원문 표현, 중요도 근거, 음성 등장 구간, 필기 페이지
- `ai_curation`: AI 사용 여부, 모델, 강의 주제, 선별 개수와 결과 상태

분석은 독립된 `learning-analysis` 단계 캐시를 사용한다. 알고리즘 버전, 원본, 판서 페이지, 전사, OCR, AI 설정이 바뀌면 캐시 키가 달라진다. 웹의 **분석 다시 실행** 버튼은 해당 단계 캐시를 강제로 갱신한다. 영상 전체 분석·OCR·Whisper를 다시 실행하지는 않는다.

## 실행 설정

터미널에서 Ollama를 실행하고 `lecture2doc setup-models`로 OCR·Qwen 기본 모델 세트를 준비한 뒤 서버를 실행한다.

```bash
source .venv/bin/activate
lecture2doc qwen-models
./serve.sh
```

모델이 설치되지 않았거나 Ollama가 꺼져 있으면 기본 필터를 사용한다. 성공적으로 내려받은 Qwen 모델 이름은 `models/qwen/selection.json`에 저장되어 다음 실행에도 유지된다. 기존 강의에서 **분석 다시 실행**을 누르면 로컬 Qwen 개념 선별을 새로 수행한다. 설치와 오류 해결은 [로컬 Qwen 안내](QWEN_LOCAL.md)를 참고한다.

## 한계와 검증 과제

- AI는 OCR·전사 후보와 입력된 문맥에 근거해 선별한다. 전사 오류나 잘못 읽은 OCR은 결과에 영향을 준다.
- 후보에 없는 개념은 새로 추가하지 않으므로 OCR이 핵심 용어를 놓치면 AI도 그 용어를 선별할 수 없다.
- 긴 강의는 비용과 입력량을 줄이기 위해 전사 일부를 시간상 고르게 추려 전달한다. 누락된 세부 구간은 AI 선별에 반영되지 않을 수 있다.
- AI 선별이 사람의 판단이나 시험 출제 가능성을 보장하지 않는다. 실제 강의 여러 개에서 사람이 고른 핵심 개념과 비교해야 한다.
- 한국어 조사 정규화는 기본적인 규칙일 뿐 완전한 형태소 분석이 아니다.
- Ollama가 꺼져 있거나 모델이 설치되지 않았거나 로컬 추론에 실패하면 기본 필터로 대체되므로 선별 품질이 낮아질 수 있다.

중요도 점수는 별도로 규칙 기반으로 유지한다. 이후 실제 강의의 정답 표식과 비교해 중요도 계산과 AI 선별을 각각 평가·개선해야 한다.
